# 💳 Sistema Bancário em COBOL

Este é um projeto desenvolvido em **COBOL** para demonstrar lógica de programação estruturada voltada para o processamento de dados financeiros e sistemas legados.

## 🚀 Tecnologias Utilizadas
* **COBOL** (GnuCOBOL)
* **Lógica Procedural**

## ⚙️ Como Executar
1. Instale o compilador GnuCOBOL no seu sistema:
   ```bash
   sudo apt-get install gnucobol  # Ubuntu/Debian
   ```
